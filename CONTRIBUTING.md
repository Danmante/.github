# Contributing to Danmante

Thank you for contributing to Danmante. This repository is designed to support a professional, responsible, and safety-first collaboration model.

## How to contribute

1. Fork the repository and create your branch.
2. Keep changes focused on one concern.
3. Ensure relevant tests, linting, and documentation updates are included.
4. Open a pull request with a clear summary and risk assessment.

## Required review areas

Any change involving clinical, pharmacy, verification, billing, identity, payment, or jurisdiction logic must be reviewed against:

- `CLINICAL_SAFETY.md`
- `SECURITY.md`

## Development standards

- Use clear commit messages.
- Prefer small, reviewable pull requests.
- Document decisions that affect patient safety or compliance.
- Do not commit secrets or credentials.

## Code of conduct

All contributors are expected to follow the repository's code of conduct and maintain a respectful, professional working environment.
