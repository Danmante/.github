# Security Policy

## Reporting a vulnerability

Please report security issues privately and responsibly.

- Do not open a public issue for a suspected vulnerability.
- Contact the maintainers through the repository security contact process.
- Include steps to reproduce, potential impact, and any relevant evidence.

## Response expectations

We aim to acknowledge valid reports in a timely manner and to coordinate remediation with maintainers and affected stakeholders.

## Scope

This policy applies to the Danmante project infrastructure, application code, and operational workflows in scope of this repository.
